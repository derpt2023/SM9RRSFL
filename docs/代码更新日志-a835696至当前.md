## 2. 六方案实验支持

```text
sm9rrs vert fedredefense krum ding13 fedavg
```

### 2.1 VERT

新增：

```text
sm9rrsfl/vert.py
tests/test_vert.py
```

主要实现内容：

- 前两轮使用全部有效客户端建立纵向更新历史；
- 使用固定随机投影器将模型更新映射到低维空间；
- MNIST 参数规模允许时使用稠密随机全连接投影；
- 稠密投影矩阵预计超过 `256 MiB` 时，切换为固定稀疏符号哈希投影，避免 CIFAR 大模型出现不可执行的内存占用；
- 使用三层预测器和两个可训练逐元素集成系数预测客户端下一轮更新；
- 使用预测更新与实际更新的余弦相似度评分；
- 选择 Top-k 客户端，并按非负相似度归一化聚合；
- 被排除客户端只在当轮不参与聚合，其历史用当轮全局更新替代，不执行永久撤销；
- VERT 状态进入逐轮检查点，支持断点恢复。

新增命令行参数：

```text
--vert-history-window
--vert-projection-dim
--vert-predict-epochs
--vert-predict-lr
--vert-top-k
```

当前重要限制：`--vert-top-k 0` 会根据实验配置中的真实恶意比例估算诚实客户端数量。这可以作为 `VERT-known-f` 或论文复现实验，但不适合作为“不依赖恶意比例先验”的最终公平主对比。自适应 Top-k/分数间隙选择尚未实现。

### 2.2 FedREDefense

新增：

```text
sm9rrsfl/fedredefense.py
tests/test_fedredefense.py
```

主要实现内容：

- 为每个客户端持续维护合成图像、软标签和可训练合成学习率；
- 从当前全局模型出发执行可微合成 SGD；
- 以“合成更新与客户端更新的参数平方误差 / 客户端实际更新平方范数”作为归一化重构误差；
- 根据阈值筛选客户端；
- 被拒绝客户端通过联邦训练主流程的黑名单状态在后续轮次保持不可用；
- 通过筛选的客户端采用等客户端权重聚合，保持官方实现口径；
- 合成状态和筛选状态支持检查点序列化与恢复；
- 明确要求 PyTorch 高阶自动微分环境。

新增命令行参数：

```text
--fedre-threshold
--fedre-initial-iterations
--fedre-max-iterations
--fedre-synthetic-steps
--fedre-images-per-class
--fedre-image-lr
--fedre-label-lr
--fedre-teacher-lr
--fedre-teacher-lr-lr
```

代码默认值仍采用官方 Fashion-MNIST 配置迁移口径，其中 `--fedre-teacher-lr` 默认为 `0.1`。针对本项目共享客户端学习率 `0.05` 的下一次实验，建议显式设置 `--fedre-teacher-lr 5.0` 作为校准起点；该数值尚未写成项目默认值，也尚未完成独立干净校准。

## 3. Ours 逐客户端诊断输出

新增 `ClientDiagnosticRecord`，并为每次 Ours 实验生成：

```text
sm9rrs_diagnostics.csv
```

每条记录对应一个客户端在一轮中的检测和权重状态，主要字段包括：

- 实验配置：数据划分、Dirichlet 参数、客户端数、恶意比例；
- 轮次、客户端标识、任务匿名标签；
- 仅用于实验审计的 `is_malicious` 真值；
- `z_sigma`、`z_direction`；
- `sigma_delta`、`cosine_similarity`；
- 两个阈值条件是否分别越界；
- 是否判为疑似、是否增加 `Count`；
- 惩罚/恢复前权重和归一化前权重；
- 实际归一化聚合权重；
- `Count` 更新前后值；
- 追踪请求、待处理和撤销状态；
- 检测原因。

实验身份真值只写入诊断文件，不参与检测、聚合、阈值选择或客户端筛选。

`SuspicionWeightManager` 的返回结果增加 `pre_normalization_weights`，用于区分：

- 惩罚/恢复状态机实际设置的权重；
- 所有当前参与客户端重新归一化后的实际聚合权重。

诊断记录随逐轮检查点保存和恢复；检查点 schema 从 `2` 升级到 `3`。旧实验未保存客户端级 Z-Score，不能从历史摘要反推该诊断文件，必须用新目录或 `--no-resume` 重新运行。

## 8. 已知问题与未完成事项

1. VERT 的 `--vert-top-k 0` 仍使用真实恶意比例，应在正式主实验前实现或确定不依赖真值的选择规则。
2. FedREDefense 默认 `teacher_lr=0.1` 与本项目 `lr=0.05` 不匹配，曾导致正常客户端在首轮被全部拒绝；`teacher_lr=5.0` 只是下一次干净校准起点。
3. Ours 仍会把当前异常特征写成下一轮的 `last_observed`，持续攻击可能污染相邻差分参考。讨论中的“仅由最近 K 个正常接受特征形成稳健锚点”尚未实现。
4. 当前图例采用项目缩写 `TAD`；论文正文首次出现时必须给出全称及引用，避免将其误写成原作者明确命名的官方缩写。
5. 当前改动尚未提交，不能假设远端仓库或全新克隆已经包含六方案和诊断功能。
