# CIFAR 无密码学攻击预实验

本入口新增标签翻转和固定倍率缩放实验。它只读复用 `cifar-best` 的数据划分、训练计算与六法防御模块，不修改原代码、报告、结果或清单。原交替最小化攻击不在本次任务中。

默认只查看计划。当前授权范围是准备代码、测试和核对首批 48 项；尚未授权启动训练。

```bash
python run_hfcdr_attack_pilot.py
python run_hfcdr_attack_pilot.py --prepare
python run_hfcdr_attack_pilot.py --check
python run_hfcdr_attack_pilot.py --report
```

`--prepare` 只读加载本地数据、核对数据 SHA、客户端分配与恶意名单，并写入独立的 `outputs/hfcdr_attack_pilot_v1`。不下载数据，不调用训练，不创建 worker。输出目录必须全新；已有结果不覆盖。`--check` 核对代码指纹和全部受保护文件。报告保留失败、未完成及表现不佳的场景。

## 固定协议

- 6 法：HFCDR-FL（固定 R4）、FedAvg、Krum、PaperVERT、AlignIns、PriorFreeTAD。
- 2 分布：IID 与 Dirichlet α=0.5；100 客户端；全体尚未移除的客户端每轮参与。
- 4 条件：clean、40% 标签翻转、40% 缩放 λ=2、40% 缩放 λ=5。
- 首批种子 2026111601，共 48 项；第二种子 2026111602 仅保留在说明中，不生成或自动运行。
- 150 轮，普通 SGD 学习率 0.05，每轮衰减 0.99；每客户端 1 epoch、batch 50；第 25 轮开始攻击，HFCDR 初始化 20 轮。
- 训练/验证/预留攻击辅助数据为 40000/7500/2500，固定划分种子 20261013。预实验只评估验证集的 7500 张图像和其中全部类别 5 图像（750 张）。官方测试集不会用于优化或评估；数据加载器读取的官方数组不传给训练循环。预留辅助集只做一致性校验，不传入训练上下文。
- 标签翻转将恶意客户端自己本地的全部类别 5 标签改为 7；其余标签不变。没有源类样本的恶意客户端照常保留。缩放只在攻击期将该客户端标签投毒训练产生的完整更新乘以 λ。λ=1 与标签翻转等价。
- 不继承 AM 的辅助目标128、boost15、target-lr0.01、交替训练或目标图像增强；标签投毒使用普通本地 SGD。
- 同种子共享初始参数、分区、恶意名单和批次随机安排。每个任务独立初始化；六法后续全局模型按各自聚合自然分化。Krum 收到真实恶意数量上界；其他防御不接收真实恶意身份、比例、源目标类别或攻击起点。
- 保留各法原本的样本权重/均匀权重/裁剪规则。TAD 零权重不回退均匀聚合；HFCDR/AlignIns 裁剪后不重新归一化。

## 无密码学边界

`hfcdr_pilot_runtime.py` 不导入旧 FL 入口、SM9、签名、验签、密钥生成、追踪或原生密码桥。固定客户端编号只是服务器历史状态的索引。HFCDR 直接调用冻结的 `LongitudinalSVDDetector` 和权重公式；满足严重异常或累计阈值时，服务器直接确认移除并清除该客户端历史。本轮系数立即为零。对同一批更新，检测和权重方程与原 R4 一致。

所有训练仍使用冻结的 `TorchTrainingContext.local_train_delta_resident`。标签张量仅在单个恶意客户端调用期间切换，调用结束或异常时恢复，不修改原始数据或其他客户端的标签。

## 测试与后续执行

```bash
python -m unittest discover -s tests -p 'test_hfcdr_attack_pilot.py' -v
```

测试使用固定向量、玩具数据和替代本地训练器验证调度边界；不执行 CIFAR 实验或本地 SGD。VERT 的拟合过程在循环测试中替换为无优化的测试函数，但实际 PaperVERT 实例、预测、筛选及历史接口仍检查；其冻结算法源码 SHA 单独校验。因此本地测试不等于 CUDA 端已完成训练验证。

后续获得启动授权后，显式 `--run-task TASK_ID` 才会训练一项。当前没有自动批量调度、续跑或重试。worker 要求一个显式可见的 CUDA GPU，至少 8192 MiB 空闲，并严格核对原 Python/NumPy/Torch/sklearn/CUDA/cuDNN/GPU 型号与数值配置；本地 CPU 环境不能误启动正式任务。一个输出目录同时只允许一个 worker。

任务保留逐轮指标、实际聚合系数、翻转样本量、检测器绑定和健康检查。结果异常时保留失败记录。永久移除的客户端不再训练，不因其已移除而改变固定样本基准。新计时直接记录无密码学运行，排除数据/上下文准备和落盘回调，不沿用旧扣减计时。

## 预先固定的评价规则

主要窗口为第 141～150 轮均值，辅助窗口为第 25～150 轮均值。完整曲线和最终值都保留，不把轮次当独立重复。

FedAvg 相对同分布同种子的 clean ASR 至少增加15个百分点才称攻击有效。HFCDR 相对自身 clean 的准确率下降不超过3个百分点、ASR 增加不超过5个百分点；与其余五法最高准确率相差不超过1.5个百分点；攻击额外 ASR 相对 FedAvg 至少削减80%。健康要求完整150轮、无非有限更新、诚实误移除不超过10%、无空聚合及连续5轮诚实贡献损失至少99%的停滞。

健康失败的基线也保留展示，不通过筛掉不利方法提高排名。缺失/失败的比较单元不能判为通过。首批通过仅是单开发种子初步证据；不自动开始第二种子、正式测试集或其他恶意比例。
